# TODO-list Application
Command-line ToDo list application in C

## Features
You can:
- Add;
- List;
- Update;
- Mark as done;
- Save;
- Load;
- Delete.

## How to compile?
In your terminal run the following command:

```bash
gcc -Iheaders main.c todo.c storage.c -o todo. 
```

To run the compiled exe file executable:

```bash
 ./todo
 ```
